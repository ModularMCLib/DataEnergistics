# Extended Crafting（扩展合成）

| 机器 | 连接目标 | 接单与发配 |
| --- | --- | --- |
| Basic／Advanced／Elite／Ultimate 工作台 | 对应等级工作台 | 等级和配方网格匹配，网格与输出为空；使用原生菜单取结果。 |
| 自动工作台 | 自动工作台本体 | 网格、输出为空；原生开关已开启并有 FE；等待机器计时。 |
| 组合合成 Combination Crafting | 组合合成核心 | 中央和基座空闲、基座数量符合配方；核心供能并启动原生合成。 |
| 末影／通量合成器 Ender／Flux Crafter | 合成器本体 | 九宫格为空，配方和周边装置匹配；通量路线需要 FE。 |
| 量子压缩器 Quantum Compressor | 压缩器本体 | 累计材料、进度和库存为空；关闭弹出模式并供能；输入按配方补齐。 |

## 组合合成

供应器连接核心，基座与核心同高，两个水平轴上各可偏移至多三格。基座的返还物应写入样板，中央主材料选用无原生合成返还物的配方。末影和通量合成器会消耗网格输入，样板只声明主产物。

## 量子压缩器

从 JEI 或 EMI 转移配方。编码会把材料补到配方所需数量，并保留选中的催化剂。机器的催化剂槽留空，由供应器投入订单中的实际催化剂，再按单槽容量逐批投入材料。

催化剂能与材料独立识别时，数据核心／三位一体 CPU 为每台并发机器借一份，结算时归还，样板输出只列压缩产物。已声明催化剂返还的旧样板，以及无法区分两种输入角色的样板，仍按样板声明返还催化剂。

样板按单轮数量编码。一轮只使用一种完整的材料 key。使用 Tag 模式时，同一种合规变体要能凑齐该轮材料。
