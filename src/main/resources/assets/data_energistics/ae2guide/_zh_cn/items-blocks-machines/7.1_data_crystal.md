## 改造站升级

将工具放入[数位化改造研究站](6.22_digital_transformation_research_station.md)，按物品支持的项目研究储能、加速、伤害、挖掘速度、数据流存储和工具特技。升级卡作为研究材料消耗，元件工作台不再安装卡片；旧卡不会解锁研究。

储能研究共三级，最大容量为基础容量 × (1 + 8 × 储能等级)；支持加速研究的工具共有三级加速。切割刀保留基础256字节数据流存储，研究后增加到512字节。其他工具的数据流存储由独立研究解锁。

| 工具 | 特技研究 |
| :--- | :--- |
| 水晶剑 | 满冷却攻击消耗20数据流叠加进制冗余 |
| 水晶斧 | 消耗20数据流连锁伐木 |
| 水晶镐 | 消耗20数据流复制矿物 |
| 水晶锄 | 消耗20数据流保持耕地湿润 |
| 水晶锹 | 消耗20数据流范围挖掘，潜行右键切换范围 |
| 切割刀 | 传送锚选择范围由9区块扩大到11区块 |
| 数据三叉戟 | 投出后形成驱赶或吸引生物的力场，半径4格，消耗160 AE/秒 |

进制冗余只负责叠层附加伤害与满层爆发；水晶剑、光剑和磁轨炮数据流弹均只叠加冗余。进制凝滞是独立效果，只暂停生物AI，结束后恢复原有AI状态，不限制玩家操作。

## 数据三叉戟

<Row><ItemImage id="data_energistics:data_trident" scale="4" /></Row>

数据三叉戟兼顾近战、投掷和生物控制。基础近战与投掷伤害均为 **17**，投掷初速度为原版三叉戟的 **1.5 倍**。它使用 AE 能量驱动，没有耐久；物品下方的能量条显示当前电量，可通过 AE 或 FE 设备充电。

### 使用方式

| 操作 | 效果与耗能 |
| --- | --- |
| 近战命中 | 消耗100 AE |
| 按住右键后松开 | 至少蓄力10 tick（0.5秒）后投出，消耗100 AE |
| 手持时潜行右键 | 切换驱赶与吸引模式，默认驱赶；当前模式会显示在物品提示中 |

近战和投掷前需要至少100 AE。投出后，生物力场使用三叉戟自身剩余的电量。

### 改造站研究

三叉戟支持以下研究，各项效果保存在这一把三叉戟上：

| 研究项目 | 效果 |
| --- | --- |
| 储能 I / II / III | 最大储能依次提高到180,000 / 340,000 / 500,000 AE；后一级需要先完成前一级 |
| 数据流存储 | 解锁256字节数据流容量，可通过[数据充能器](6.4_data_charger.md)补充，并在物品提示中查看 |
| 生物力场 | 三叉戟在飞行或落地时持续驱赶或吸引附近生物，消耗160 AE/秒 |

生物力场以投出的三叉戟为中心，作用于 **4格**内、与三叉戟之间无遮挡的非玩家生物。驱赶模式将生物推离，吸引模式将其拉近。完成生物力场研究后，即使范围内没有目标，投出的三叉戟也会持续消耗能量；电量不足时力场暂停，收回三叉戟后可以补能。

生物力场研究独立于数据流存储，使用力场需要完成对应研究并保证 AE 电量充足。储能研究可以延长一次充电后的力场持续时间。
