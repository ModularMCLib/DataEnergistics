# Avaritia（无尽贪婪）

| 机器 | 连接目标 | 接单与发配 |
| --- | --- | --- |
| Sculk／Nether／End／Extreme 工作台 | 对应等级工作台 | 等级和网格配方匹配，工作台输入输出为空；使用原生菜单取结果。 |
| Extreme Smithing | Extreme Smithing Table | 样板对应无尽锻造配方；模板、基底和三份添加材料齐全；使用原生锻造菜单。 |
| 默认／Dense／Denser／Densest 中子压缩器 | 对应压缩器 | 库存与累计材料为空，样板数量符合等级；按真实槽容量分批投料。 |

工作台等级与中子压缩器等级不能互换。Densest 压缩器的产物数量和各级材料比例按原生配方处理。复杂返还物必须是原生机器实际产生的物品，不能额外声明。
