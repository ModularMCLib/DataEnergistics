# 均分连接器

均分连接器用于编辑远程链接。它可以绑定点对点模式的数据均分塔、完整方块形态的自适应样板供应器，或完整方块形态的极限承载接口。

## 先选择宿主

手持连接器，潜行右键要编辑的宿主：

| 宿主 | 选择条件 | 主要用途 |
| --- | --- | --- |
| 数据均分塔 | 塔处于点对点模式，且与玩家同维度 | 添加或移除 AE/FE 锚点 |
| 自适应样板供应器 | 必须是完整方块，贴片不支持 | 编辑远程输入、抽回和双向目标 |
| 极限承载接口 | 必须是完整方块，接口贴片不支持 | 为指定接口槽位编辑远程目标 |

宿主和目标的维度、区块状态、目标面和 capability 会在服务器端重新检查。连接器只保存链接数据，不会强制加载远程区块。

对空气潜行右键只会清除连接器当前选择，不会删除宿主里已经保存的链接，也不会清除剪贴板。

## 链接模式

每条链接有自己的模式：

| 模式 | 行为 |
| --- | --- |
| `INPUT` | 从宿主向目标发送材料或库存内容 |
| `PULL` | 从目标抽回内容 |
| `BOTH` | 同时允许发送和抽回 |

自适应供应器和接口会按各自的输入/抽回能力筛选链接。数据均分塔仍使用点对点模式，并按塔的 AE/FE 目标设置决定是否接管目标。

重复点击同一个目标位置和目标面，会解除该链接。目标必须暴露对应的 AE、FE、通用库存或第三方适配 capability；不能把空气、宿主自身或无交互面的方块作为目标。

## 自适应供应器链接

1. 潜行右键完整的自适应供应器方块；
2. 右键目标机器或库存的实际交互面；
3. 再次点击相同位置和面即可解绑；
4. 在供应器界面选择 `INPUT`、`PULL` 或 `BOTH`，并选择 `优先` 或 `轮询`。

供应器贴片不能成为连接器宿主。远程链接只负责传输，目标机器仍需满足原生结构、能源、光路、魔力和配方条件。

## 极限承载接口链接

1. 潜行右键完整的极限承载接口；
2. 使用 `Ctrl + Shift + 滚轮` 选择接口槽位；
3. 右键目标方块的实际交互面添加或移除该槽位的链接；
4. 对每个槽位分别设置输入、抽回或双向模式。

接口的每个槽位有独立的链接顺序、优先/轮询策略和游标。卸下容量卡后，已锁定槽位的链接会保留，但暂停执行；重新安装容量卡后恢复。

## 选择、模式与剪贴板

- `Shift + 滚轮`：选择当前链接；
- `Ctrl + 滚轮`或对空气右键：切换新链接使用的 `INPUT`、`PULL`、`BOTH` 模式；
- `Ctrl + A`：选择宿主的全部链接；
- `Ctrl + C`：复制当前链接或全部选中的链接；
- `Ctrl + X`：剪切当前链接或全部选中的链接；
- 在相同类型的宿主上 `Ctrl + V`：粘贴链接。

剪贴板保留绝对坐标、目标面、接口槽位、模式和链接顺序。粘贴到不同宿主类型、不同维度或未解锁槽位时会拒绝操作，不会部分写入目标。

## 数据均分塔

均分连接器只能绑定处于点对点模式的数据均分塔。绑定流程是：

1. 潜行右键数据均分塔，选择该塔；
2. 在同一维度、作用范围内右键需要接入的 AE 或 FE 设备；
3. 成功后，目标会出现在塔的控制界面中。

锚点必须在范围内，并暴露 AE 节点或可输入/输出的 FE 接口。纯输出 FE 设备也可以绑定。连接器不能直接绑定跨维度锚点，但已经接管的子网成员可以位于其他维度。

把已绑定连接器放在副手或专用饰品栏中时，新放置的兼容设备也会自动尝试连接到该塔。

## 持久化与排障

- 链接顺序、模式、槽位和轮询游标会随宿主保存；
- 目标暂时卸载时，链接不会自动删除；
- 删除最后一条抽回链接且没有其他工作后，自适应供应器才允许休眠；
- 远程链接已配置但当前方向没有匹配目标时，结果为空；完全没有链接时，供应器才会回退到相邻目标；
- “宿主不存在、未加载或不在当前维度”：重新加载目标区块并确认维度；
- “目标无效”：检查目标面、capability 和是否误点了宿主自身；
- “接口槽位未解锁”：安装容量卡或切换到已解锁槽位；
- “均分塔不是点对点模式”：打开塔界面切换范围模式；
- “剪贴板类型或维度不一致”：重新绑定同类型、同维度的宿主后再粘贴。
