# Distribution Connector

The Distribution Connector edits remote links. It can bind a point-to-point Data Distribution Tower, a full-block Adaptive Pattern Provider, or a full-block Extreme Capacity Interface.

## Select a host

Hold the connector and sneak-right-click the host you want to edit:

| Host | Selection condition | Main use |
| --- | --- | --- |
| Data Distribution Tower | The tower is in point-to-point mode and shares the player's dimension | Add or remove AE/FE anchors |
| Adaptive Pattern Provider | Full block form only; parts are unsupported | Edit remote input, pull, and bidirectional targets |
| Extreme Capacity Interface | Full block form only; interface parts are unsupported | Edit remote targets for one interface slot |

The server rechecks the host and target dimension, loaded chunk, target face, and capability. The connector stores links but never force-loads a remote chunk.

Sneak-right-clicking air only clears the connector's current selection. It does not remove links already saved in the host or clear the clipboard.

## Link modes

Each link has its own mode:

| Mode | Behavior |
| --- | --- |
| `INPUT` | Send materials or inventory contents from the host to the target |
| `PULL` | Pull contents back from the target |
| `BOTH` | Allow both directions |

Adaptive providers and interfaces filter links according to their own input and pull capabilities. A Data Distribution Tower still uses point-to-point mode and its AE/FE target settings.

Right-clicking the same target position and face again removes that link. A target must expose an AE, FE, generic-inventory, or supported third-party capability; air, the host itself, and a face without an interaction capability are invalid targets.

## Adaptive provider links

1. Sneak-right-click a full-block Adaptive Pattern Provider.
2. Right-click the actual interaction face of a target machine or inventory.
3. Click the same position and face again to unlink it.
4. Choose `INPUT`, `PULL`, or `BOTH`, then choose `Priority` or `Round Robin` in the provider interface.

Provider parts cannot host connector links. A remote link only transports contents; the target machine still needs its native structure, power, light path, mana, and recipe conditions.

## Interface links

1. Sneak-right-click a full-block Extreme Capacity Interface.
2. Use `Ctrl + Shift + Wheel` to select an interface slot.
3. Right-click the actual target face to add or remove a link for that slot.
4. Set the slot's links to input, pull, or both.

Each interface slot has independent link order, priority/round-robin policy, and cursor. Removing a Capacity Card keeps links on locked slots but pauses their execution; reinstalling the card restores them.

## Selection, modes, and clipboard

- `Shift + Wheel`: select the current link;
- `Ctrl + Wheel` or right-click air: cycle the mode for new links through `INPUT`, `PULL`, and `BOTH`;
- `Ctrl + A`: select all links on the host;
- `Ctrl + C`: copy the current link or all selected links;
- `Ctrl + X`: cut the current link or all selected links;
- `Ctrl + V` on a host of the same type: paste the links.

Clipboard data retains absolute positions, target faces, interface slots, modes, and link order. Pasting to another host type, another dimension, or a locked slot is rejected without partially modifying the destination.

## Data Distribution Tower

The connector can bind only a point-to-point Data Distribution Tower:

1. Sneak-right-click the tower to select it.
2. Within the same dimension and tower range, right-click an AE or FE device.
3. A successful target appears in the tower control interface.

The anchor must be in range and expose an AE node or an FE input/output capability. Source-only FE devices are valid. A connector cannot directly bind a cross-dimensional anchor, although members of an accepted subnet may be cross-dimensional.

An already bound connector in the offhand or dedicated trinket slot also lets newly placed compatible devices attempt automatic connection to that tower.

## Persistence and troubleshooting

- Link order, mode, slot, and round-robin cursor are saved with the host.
- A temporarily unloaded target does not delete its link.
- An adaptive provider may sleep only after its last pull-capable link is removed and it has no other work.
- Configured links with no matching target in the requested direction return an empty result; a provider falls back to adjacent targets only when no links are configured.
- “Host missing, unloaded, or in another dimension”: load the target chunk and check the dimension.
- “Invalid target”: check the target face, capability, and whether the host itself was clicked.
- “Interface slot locked”: install a Capacity Card or choose an unlocked slot.
- “Tower is not in point-to-point mode”: switch the tower back to point-to-point mode.
- “Clipboard type or dimension mismatch”: bind a compatible host in the same dimension before pasting.
