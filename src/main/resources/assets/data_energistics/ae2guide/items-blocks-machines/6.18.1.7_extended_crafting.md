# Extended Crafting

| Machine | Target | Admission and dispatch |
| --- | --- | --- |
| Basic/Advanced/Elite/Ultimate tables | Matching table tier | Tier and recipe grid match; grid and output are empty; the native menu takes the result. |
| Auto table | Auto table | Grid and output are empty; the native switch is enabled and FE is available; wait for native timing. |
| Combination Crafting | Combination core | Core and pedestals are idle, and pedestal count matches the recipe; the core supplies power and starts native fusion. |
| Ender/Flux Crafter | Crafter block | Nine-grid inventory is empty, recipe and surrounding devices match; Flux Crafter requires FE. |
| Quantum Compressor | Compressor | Accumulated material, progress, and inventory are empty; pop-out mode is disabled and power is available; inputs are completed from the selected recipe. |

## Combination Crafting

Connect to the core and place the pedestals at the same height, up to three blocks away along each horizontal axis. Declare pedestal returns in the pattern. Use recipes whose central input has no crafting remainder. The Ender and Flux crafters consume their grid inputs, so their patterns declare only the main result.

## Quantum Compressor

Transfer the recipe from JEI or EMI. Encoding expands the material to the recipe's full count and keeps the selected catalyst. Keep the catalyst slot empty on the machine. The provider inserts the actual catalyst from the order and feeds the material in slot-sized portions.

For a catalyst that the pattern can distinguish from its material, the Data Core or Trinity CPU borrows one catalyst per active machine and returns it at settlement. The encoded output lists the compressed result. Existing patterns that declare the catalyst return and patterns with indistinguishable material and catalyst roles use the declared return.

Encode one round at a time. Each compression round uses a single full material key. With Tag matching, any valid variant may supply the round if enough of that variant is available.
