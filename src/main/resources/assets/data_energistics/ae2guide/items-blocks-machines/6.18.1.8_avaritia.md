# Avaritia

| Machine | Target | Admission and dispatch |
| --- | --- | --- |
| Sculk/Nether/End/Extreme tables | Matching table tier | Tier and grid recipe match; table inputs and output are empty; the native menu takes the result. |
| Extreme Smithing | Extreme Smithing Table | Pattern selects an Extreme Smithing recipe; template, base, and three additions are present; the native smithing menu performs the craft. |
| Default/Dense/Denser/Densest Neutron Compressor | Matching compressor | Inventory and accumulated material are empty, and pattern amounts match the tier; inputs are delivered in real slot-sized portions. |

Table tiers and Neutron Compressor tiers cannot substitute for one another. The Densest compressor's output count and each tier's material ratio follow the native recipe. Declare complex returns only when the native machine produces them.
