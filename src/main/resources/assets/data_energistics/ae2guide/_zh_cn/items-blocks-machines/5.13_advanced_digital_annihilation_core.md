# 数位化进阶成毁核心

<ItemImage id="data_energistics:advanced_digital_annihilation_core" scale="6" />

数位化进阶成毁核心在[数据重组器](6.3_data_reassembler.md)中制作，将形成核心与破坏核心整合为高级材料。

<Recipe id="data_energistics:data_reassembler/advanced_digital_annihilation_core" />

## 单轮材料

| 材料 | 数量 |
| --- | --- |
| ME 控制器 | 1 |
| 形成核心 | 16 |
| 破坏核心 | 16 |
| ME P2P 通道 | 4 |
| 量子纠缠态奇点 | 6 |
| 数据残存晶体 | 3 |
| 数据处理器 | 8 |
| 记忆合金锭（标签） | 7 |
| 数蚀液 | 2250 mB |
| 数据流 | 1567 |

每轮基础产出为 **1 个核心**。形成核心和破坏核心是**各 16 个**；流体与数据流要分别投入流体槽和特殊资源槽。
