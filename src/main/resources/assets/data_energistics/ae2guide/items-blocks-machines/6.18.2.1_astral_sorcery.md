# Astral Sorcery

The interface dynamically registers Astral Sorcery Lumen types, constellations, and Liquid Starlight.

| Resource | Link and use |
| --- | --- |
| Lumen | The interface creates a native Lumen source node. Astral Sorcery networks can read Lumen available in ME, and nearby external Lumen sources can also be imported into ME. |
| Constellation | Use Astral Sorcery's own linking tool to connect the interface transmission node to a receiver that requests constellations. The ME network sends constellations required by the active recipe. |
| Liquid Starlight | Import it into the ME network through the interface's external fluid input, using an adjacent tank or pipe. |

Astral native transmission packets can also record constellations produced by linked receivers as AE resources.
