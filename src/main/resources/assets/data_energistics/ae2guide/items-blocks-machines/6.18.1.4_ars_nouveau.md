# Ars Nouveau

| Machine | Target | Admission and dispatch |
| --- | --- | --- |
| Enchanting Apparatus | Apparatus block | Center inventory is empty and the Arcane Core and pedestal layout work; peripherals are inserted before the center; actual returns are collected. |
| Imbuement Chamber | Chamber | Center inventory is empty, recipe pedestals are available, and source capacity is sufficient; central consumables scale with the order while catalysts are held by a reusable session. |

Place the Arcane Core directly below the Enchanting Apparatus with the matching facing axis. Put the pedestals within the apparatus's native scan range. For a recipe that uses Source, place a supplied Source Jar nearby.

For the Imbuement Chamber, place the recipe's pedestals in the chamber's surrounding positions. Transfer the central input and all recipe catalysts into the pattern. Re-encode older patterns that list the catalysts as outputs. The Data Core or Trinity CPU borrows one set per active chamber and returns it once after the last round. The provider can recover the old pedestal setup and load the set selected for the new recipe.
