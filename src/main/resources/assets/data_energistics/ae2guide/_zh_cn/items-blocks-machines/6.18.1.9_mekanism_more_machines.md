# Mekanism More Machines

仅在安装 Mekanism More Machines 与 Applied Mekanistics 时注册。适配范围为下表六种 Large 大机器，不包含普通机器、工厂或复制器。连接外壳方块也会沿 Bounding Block 定位主机，并同时占用外壳和主机。

| Large 机器 | 输入 → 输出 | 条件 |
| --- | --- | --- |
| Chemical Infuser | 两种化学品 → 化学品 | 输入、输出槽和罐为空。 |
| Pigment Mixer | 两种颜料 → 颜料 | 输入、输出槽和罐为空。 |
| Solar Neutron Activator | 化学品 → 化学品 | 保留阳光等原生条件。 |
| Electrolytic Separator | 流体 → 两种化学品 | 两侧排放模式设为 IDLE，并声明两项输出。 |
| Rotary Condensentrator | 流体 ↔ 化学品 | 下单前选好方向，操作期间保持模式不变。 |
| Antiprotonic Nucleosynthesizer | 物品＋化学品 → 物品 | 整轮化学品、能源和输入输出容量充足。 |

供应器按真实端口容量持续补料并分别回收产物。机器槽、罐、处理模式和结构都必须空闲且正确。
