# Neo Vitae

The interface automatically discovers loaded Ara Vitae targets within seven blocks along each axis. It fills their fluid tanks with Essentia Vitae from the ME network's shared blood resource.

- Each transfer supplies up to 256 mB. Any amount rejected by the fluid tank remains in the network.
- Feed compatible blood fluid into the interface's external fluid input to store it as the shared blood resource.

For altar setup and processing conditions, see [Neo Vitae packaged crafting](6.18.1.12_neo_vitae.md).
