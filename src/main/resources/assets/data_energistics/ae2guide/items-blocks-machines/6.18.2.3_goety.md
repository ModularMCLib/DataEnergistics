# Goety

The interface automatically discovers loaded Dark Altars within seven blocks along each axis. Place the Cursed Cage directly below the altar, also within that range.

| Resource or automatic behavior | Target |
| --- | --- |
| Goety Soul | The cage below an active Dark Altar. The interface uses the current ritual's cost to refill the cage's totem or its eligible owner. |
| Enchanting experience | Supported Dark Altar enchanting rituals. The adapter automatically supplies the ritual caster with experience from the ME network. |

The interface supplies experience automatically when a caster starts a supported enchanting ritual. For enchanting dispatched by the packaged provider, see [Goety packaged crafting](6.18.1.15_goety.md).
