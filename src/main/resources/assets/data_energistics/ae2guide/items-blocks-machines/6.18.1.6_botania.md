# Botania

| Machine | Target | Admission and dispatch |
| --- | --- | --- |
| Petal Apothecary | Apothecary | Inventory is empty. Bucket patterns require an empty basin. Encoding adds the water bucket and finishing reagent, then returns the empty bucket and result. |
| Mana Pool | Pool | Recipe mana and any catalyst block are available; the adapter drops input entities and invokes native infusion item by item. |
| Elven Gateway | Gateway core | Multiblock is valid, the gateway was opened in advance, no trade is pending, and nearby pools have enough mana. |
| Terrestrial Agglomeration Plate | Plate | Base structure is valid, the plate has no item entity, and the machine is idle. |
| Runic Altar | Altar | Inventory is empty, cooldown is over, and a mana spreader can reach it; finishing uses Botania's native action. |
| Botanical Brewery | Brewery block | Inventory is empty, recipe and brew container match, and mana is available; inputs are dispatched by cycle and recipe outputs and container remainders are collected. |

Encoding adds the actual buckets, reagents, and returns required by the Petal Apothecary and Runic Altar. Players must open the Elven Gateway in advance. Every route keeps Botania's native mana requirements.
