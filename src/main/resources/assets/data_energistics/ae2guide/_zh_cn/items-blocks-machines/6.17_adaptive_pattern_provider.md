# 自适应样板供应器

自适应样板供应器会读取供应器槽中的兼容样板供应器，并继承它的名称、图标、样板槽数量、配方类别和已注册的特殊行为。它不需要为每一种第三方供应器单独建造一个方块。

</Row>

- 方块形态可以向多个方向输出材料，也支持远程连接器链接。
- 贴片形态安装在线缆上，主要向贴片朝向的一侧输出材料。
- 两种形态共享继承、分页和升级规则，但**贴片不能作为连接器的远程宿主**。
- 手持升级件右键普通 AE2 样板供应器或供应器贴片，可以原位升级并保留样板、名称和配置。
- 每次升级消耗一个升级件。

## 放入供应器

将兼容的供应器放入自适应供应器的供应器槽后，界面会显示被继承的供应器名称和图标。供应器槽中的数量会直接影响总样板槽数：

```text
总样板槽数 = 单个被继承供应器的样板槽数 × 供应器数量
```

同一个稳定的供应器物品状态应始终解析成一致的名称、图标、槽数和能力。无法识别的物品不会被当成普通供应器强行执行。

## 容量卡

<Row>
  <ItemLink id="ae2:capacity_card" />
  <ItemImage id="ae2:capacity_card" />
</Row>

基础最多放 4 个供应器，每张容量卡再增加 4 个，最多安装 3 张：

| 容量卡 | 供应器数量上限 | 继承标准 AE2 供应器时的样板槽 |
| ---: | ---: | ---: |
| 0 | 4 | 36 |
| 1 | 8 | 72 |
| 2 | 12 | 108 |
| 3 | 16 | 144 |

更换供应器类型或卸下容量卡前，先取出超过新上限的样板。界面会尝试把溢出的供应器和样板退还给玩家；已经进行中的任务仍按原路线处理。

## 红石调整卡

<Row>
  <ItemLink id="data_energistics:redstone_tuning_card" />
  <ItemImage id="data_energistics:redstone_tuning_card" />
</Row>

安装红石调整卡后可以在两种模式之间切换：

- **发送时输出脉冲**：每次向目标设备发送一批材料时输出一次短红石脉冲；
- **脉冲触发请求**：每收到一次红石脉冲，为当前所有可下单样板各请求一次主产物。

连续发配过快时，相邻设备可能合并红石脉冲。需要严格逐次触发时，同时使用阻挡模式或合成锁定。

## 目标与连接

自适应供应器可以直接把材料发送到相邻目标，也可以通过[均分连接器](6.19_data_distribution_connector.md)把方块形态绑定到同维度、已加载的远程目标。

- 连接器宿主必须是完整方块，不能是供应器贴片；
- 每条链接保存目标位置、目标面和链接模式；
- `INPUT` 向目标发送材料，`PULL` 抽回目标内容，`BOTH` 同时支持两个方向；
- `优先` 从注册顺序靠前的链接开始，`轮询` 从上次游标继续；
- 远程链接不会代替目标机器本身的多方块结构、能源、光路或魔力供应；
- 远程目标区块必须已加载，链接不会主动加载区块。

连接器的按键、槽位选择、复制粘贴和解绑规则统一见连接器页面。封包机器路线的具体条件见[数位化封包样板供应器](6.18_digital_packaged_pattern_provider.md)。

## 配方类别与特殊能力

自适应供应器只会把已经注册且实际实现的配方类别和能力视为可用。供应器来自哪个 Mod，不能单独证明它支持某种特殊行为；显示名称也不能用来判断是否兼容。

放入供应器后，样板查看器会把当前配方类别和工作方块与 profile 声明进行匹配。只有两者都符合，样板才会被标记为当前供应器可用。

已注册的能力可能包括特殊陨石处理、高级样板、过滤输入、机械合成和共振处理。能力可以组合，但未声明的能力不会自动添加按钮或派发逻辑。

## 切换、拆除与恢复

- 切换供应器后，新订单只使用当前选中的路线；旧路线已经接收的材料、产物和会话仍必须完成或结算。
- 暂时离线、断开连接器或切换模式不能当作没有资产；先排空旧缓存，再开始新的后台操作。
- 卸下容量卡后，锁定的槽位停止接收新样板，但已存在的配置和任务不会被静默删除。
- 拆除宿主时，正在执行的封包任务可能生成恢复凭证；必须把对应宿主放回原位置并按封包页面的流程恢复。

## 常见问题

- 供应器槽中的物品没有被识别：确认放入的是兼容的供应器物品，而不是显示名相似的方块。
- 样板不能下单：检查配方类别、工作方块、槽位上限和当前能力声明。
- 远程目标没有响应：确认是方块形态、同维度、区块已加载，且目标面存在输入或输出 capability。
- 红石脉冲不逐次出现：连续发配可能合并脉冲，使用合成锁定或阻挡模式。
