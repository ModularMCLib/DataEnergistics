# Packaged Machine Integrations

Each page lists the registered packaged machines for one Mod, their connection targets, machine setup, and input/output rules. See the [Digital Packaged Pattern Provider](6.18_digital_packaged_pattern_provider.md) page for the general dispatch flow.

| [Ars Nouveau](6.18.1.4_ars_nouveau.md) | Enchanting Apparatus and Imbuement Chamber |

| [Avaritia](6.18.1.8_avaritia.md) | Compressors, Infinity tables, Extreme Smithing |
| [Mekanism More Machines](6.18.1.9_mekanism_more_machines.md) | Six Large machines |
