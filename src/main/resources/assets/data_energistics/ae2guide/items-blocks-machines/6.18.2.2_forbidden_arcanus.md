# Forbidden Arcanus

The interface automatically discovers loaded Hephaestus Forges and Arcane Crystal Obelisks within seven blocks along each axis.

- Forges draw Aureal, souls, blood, and experience from ME up to the forge's current capacity. Blood and experience use Data Energistics' shared resource types.
- Insert a Soul or Corrupt Soul through the interface's external item input to add Forbidden Arcanus souls to ME.
- A valid obelisk adds Aureal to ME once per native production interval while continuing its native output.

Keep the native structures valid and leave room in ME storage for incoming Aureal.
