# Digital Supply Interface

The Digital Supply Interface supplies or recovers third-party resources through the ME network. Consumable quantities stay in ME storage. The resource markers show which types the interface has detected.

## Setup

1. Connect the interface to a powered ME network with a free channel.
2. Set up the target described on its integration page. Some adapters find nearby machines automatically. Others use a [Distribution Connector](6.19_data_distribution_connector.md) link or the other mod's linking tool.
3. For Distribution Connector links, sneak-right-click the interface and right-click the target. Select input, pull, or both as supported by the adapter.
4. Stock the resources in ME and keep the target loaded, with its native structure and power in place.
