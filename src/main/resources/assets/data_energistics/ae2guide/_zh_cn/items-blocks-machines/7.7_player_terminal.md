# 玩家终端（随身终端）

玩家终端就是背包界面中随身的小终端。它由玩家研究解锁，界面与设置跟随玩家保存，无需制作或携带单独的终端物品。

## 解锁与打开

1. 打开[数位化改造研究站](6.22_digital_transformation_research_station.md)，切换到**玩家强化**，研究“玩家终端”。
2. 默认研究需要 16 二进制、8 数据处理器和 4 记忆合金锭，另需研究过程的时间与能源。
3. 打开玩家背包，左键“玩家终端”入口展开；按住左键可以拖动入口或面板，调整位置。

右键入口预留的大终端尚未开放；使用左键展开的小终端即可。研究属于当前玩家，不会因为队友完成研究就自动获得。

## 量子网络连接

<ItemImage id="ae2:quantum_entangled_singularity" scale="4" />

准备一对 AE2 量子纠缠态奇点，一枚放入已连接 ME 网络的量子网络桥，另一枚放在随身背包或兼容的奇点饰品栏。保持桥的区块加载和网络供电；普通、未配对的奇点不能作为连接凭证。

奇点饰品栏中的凭证优先于普通背包；携带多组时，确认实际选择的网络。这里不使用无线终端的充电方式，也不依赖无线接入点的距离。

需要网络访问时消耗 **22.5 AE/t**，同一 tick 的连接费用只收取一次；存取资源、数位砧等操作还会有各自的费用。断网或供电不足时，网络存取与自动化暂停，不会把已有库存变成免费资源。

## 五种工作区

| 工作区 | 用途 |
| --- | --- |
| 合成 | 九宫格制作，可从网络补充材料 |
| 处理 | 编辑加工样板的输入输出与数量；不是替代真实机器的加工设备 |
| 锻造 | 按原生锻造配方处理装备 |
| 切石 | 选择切石配方并制作产物 |
| 数位砧 | 修理、改名、合并附魔，费用从所连接网络支付 |

合成、锻造和切石的本地操作使用实际材料。处理页用于配置样板，配置用的资源图标不能当作真实库存取出。可从 JEI / EMI 转移支持的配方，并通过工作区的编码功能制作对应样板；数位砧不支持样板编码。

数位砧的四种强化需要在研究站中分别完成**玩家终端分支**的玩家研究。[ME 数位化铁砧](6.21_me_digital_anvil.md)物品上的研究不会自动转移给随身工作区。

## 库存、磁卡与自动化

- 使用搜索、资源类型、库存 / 可合成筛选和排序查找网络资源，也可把常用资源设为置顶标记。
- 库存维持可配置资源、下限、上限及每次请求数量；需要网络内已有样板、可用合成 CPU 与材料，才能请求补货。
- “终端磁卡”是后续玩家研究，可配置磁力拾取、直接存入 ME 和背包补货；各功能开关及过滤器应按需要设置。
- 关闭面板不会自动关闭已经启用的后台补货、磁卡或库存维持；不再需要时，分别停用相应功能。

## 常见问题

| 现象 | 检查内容 |
| --- | --- |
| 背包里没有入口 | 当前玩家是否完成玩家终端研究 |
| 能打开但网络离线 | 奇点是否配对并随身携带、凭证优先级、量子桥区块、网络供电 |
| 自动合成不完成 | 样板、CPU、原料、设备与网络能源 |
| 数位砧没有强化功能 | 是否完成玩家分支研究，而不是仅升级了铁砧物品 |
