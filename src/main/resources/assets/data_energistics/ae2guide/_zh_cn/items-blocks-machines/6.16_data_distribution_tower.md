# 数据均分塔

数据均分塔用虚拟分配接管无控制器的 AE 子网，并在多个 FE 端点之间按容量填充比例均衡能量。它不会创建物理 `IGridConnection`，也不会把目标网络合并到主网络。

## 放置与启动

塔底上方需要连续 **3 格** 空间。塔底接入 ME 网络后才会工作；塔本身是普通的 `REQUIRE_CHANNEL` 设备，会消耗一个真实频道。塔接管的虚拟设备不受上游线缆 8/32 频道上限直接限制。

- 空手右键塔身：打开控制界面。
- 潜行空手右键：切换范围显示。
- 目标区块不会被强制加载；区块卸载时，目标暂时不可用，重新加载后会恢复。

## 连接模式

### 点对点连接

点对点模式只接管通过[均分连接器](6.19_data_distribution_connector.md)手动指定的锚点。绑定会持久保存，即使之后缩小范围也不会自动删除。连接器的绑定、目标面和解绑操作请按连接器页面执行。

### 范围连接

范围模式会持续发现范围内没有物理连接的单节点 Grid。多节点、已经接线或会形成桥接环的目标会显示为冲突，不会被接管。

## 目标类型

- **仅 AE**：只处理具有可用 AE 节点的设备。
- **仅 FE**：只处理能够输入或输出 FE 的设备。
- **AE 与 FE**：同时启用两种能力。

点对点模式会解析锚点六个方向暴露的 AE capability，并按节点 identity 去重。同一个锚点可以暴露多个子网；含原版 Controller、已经归属其他主网或会形成桥接环的子网会被跳过，因此一次绑定可能只部分成功。

只有锚点必须与塔同维度且位于绑定范围内。被接管的子网成员可以位于范围外或其他维度，但仍须保持区块可加载。

## 频道与租约

目标子网保留自己的 Pathing 服务，其他 Grid 服务委托给主网络。每个 `REQUIRE_CHANNEL` 节点独立申请一个虚拟租约；没有频道需求的节点不计费。未获得租约的节点保持离线，不会阻止同一子网中的其他节点上线。

频道容量按目标 Controller 情况计算：

- 含 Controller 的冲突网络不提供虚拟容量；
- 无控制器主网按 `32 × ChannelMode` 计算；
- 原版 Controller 的六个面都提供频道，包括与其他 Controller 相邻的面；
- 目标 Controller 发布正数单面容量时，使用该容量替代原版每面 32 的回退值；
- 能够直接发布权威总供给的 Controller 使用该总值；
- Infinite 模式不受有限容量限制。

原生 AE2 Pathing 先分配物理频道，塔的可用虚拟容量等于总容量减去物理占用。手动绑定优先于自动绑定，同级按首次申请顺序分配；缩容时按相反顺序回收租约。

## FE 均衡

活动塔会在同一主 Grid 上共享一次跨维度端点快照和一次均衡事务。端点包括塔覆盖范围、手动/自动绑定、已加载的从属子网成员以及 Applied Flux 网络。

均衡目标是相同的**容量填充比例**，不是相同的 FE 数量：

- 纯输出端点优先供给；
- 纯输入端点只接收；
- 普通双向端点只搬运高于或低于均衡线的部分；
- Applied Flux 网络作为双向缓存，补足机器真实可接收缺口并吸收普通来源的盈余；
- 执行前会冻结并模拟全部抽取/插入，已经均衡时不会产生真实变更；
- 短写会先补偿来源，无法补偿的 FE 进入塔的隔离能量并记录错误。

安装 Modern Industrialization 后，塔会识别其有向 MI EU 存储，换算使用服务器当前的 `forgeEnergyPerEu`。不足 1 EU 的 FE 余数在预检阶段保持不动。

## 控制界面

顶部依次显示总容量、物理占用、虚拟租约和剩余容量。设备行会显示“已分配”“等待频道”“已禁用”“等待目标”“冲突”或“桥接错误”，并显示申请/获配频道、失败原因和冻结的 FE 状态。

- `Shift + 右键`目标：关闭或恢复该目标的传输；
- `鼠标中键`有坐标目标：在世界中高亮并显示坐标；
- `Shift + 鼠标中键`有坐标目标：管理员可直接传送到目标位置。

没有坐标的逻辑节点会归组到绑定锚点，只能单独禁用，不能高亮或传送。

默认覆盖以塔为中心的 **1×1 区块**。每安装 16 张无线增幅卡，水平范围向外增加一圈：

| 无线增幅卡 | 水平范围 |
| ---: | :--- |
| 0～15 | 1×1 区块 |
| 16～31 | 3×3 区块 |
| 32～47 | 5×5 区块 |
| 48～63 | 7×7 区块 |
| 64 | 9×9 区块 |

垂直范围为塔底向下 128 格、向上 256 格，并受世界高度限制。默认 1×1 区块范围消耗 **4 AE/t**；范围内每增加一个区块，额外消耗 **8 AE/t**。

## 常见问题

- 目标不在线：先检查目标区块、塔频道、目标类型和范围。
- 点对点绑定失败：确认塔处于点对点模式，锚点同维度、在范围内并暴露 AE 或 FE capability。
- 频道不足：检查物理频道占用、Controller 容量和虚拟租约状态。
- FE 不流动：检查端点方向、容量填充比例、Applied Flux 状态和目标是否可接收。
