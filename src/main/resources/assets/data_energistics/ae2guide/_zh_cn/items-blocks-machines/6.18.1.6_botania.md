# Botania（植物魔法）

| 机器 | 连接目标 | 接单与发配 |
| --- | --- | --- |
| 花药台 Petal Apothecary | 花药台本体 | 物品为空；水桶样板要求盆内无水；编码补水桶与收尾试剂，回收空桶和产物。 |
| 魔力池 Mana Pool | 魔力池本体 | 配方要求的魔力和催化方块已具备；逐件投放物品实体并调用原生灌注。 |
| 精灵传送门 Elven Gateway | 门核心方块 | 多方块有效、门已开启、没有待交易物；附近池子有足够魔力。 |
| 泰拉凝聚板 Terrestrial Agglomeration Plate | 凝聚板 | 下方结构有效，板面无物品实体，机器空闲。 |
| 符文祭坛 Runic Altar | 祭坛本体 | 库存空、冷却结束、魔力发射器可达；投完材料后按原生方式进行收尾。 |
| 植物酿造器 Botanical Brewery | 酿造器本体 | 库存空、配方和酿造容器匹配、魔力足够；按循环投料并回收配方结果与容器余物。 |

花药台与符文祭坛由编码规则补齐实际水桶、试剂和返还物。精灵门必须先由玩家完成开启过程。所有路线都保留原生魔力条件。
