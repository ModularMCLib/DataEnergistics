# 复杂化生物芯片

复杂化生物芯片由生物材料与数据处理元件重组而成。它既是高级设备的合成材料，也能在研究后装入[数位化武器平台](7.6_digital_weapon_platform.md)，提供扩容、散热和其他能力。

<ItemImage id="data_energistics:complexified_biochips" scale="6" />

## 制作

在[数据重组器](6.3_data_reassembler.md)中制作，每轮基础产出 1 个芯片。

<Recipe id="data_energistics:data_reassembler/complexified_biochips" />

除图中的物品材料外，还需要 **2350 mB 数蚀液和 67 二进制**。二进制属于特殊资源，应放入对应的资源输入槽，不能用普通物品代替。

## 研究与安装

1. 将芯片放入[数位化改造研究站](6.22_digital_transformation_research_station.md)的目标槽，切换到物品升级。
2. 完成“数位化武器平台研究”，再按前置关系研究所需节点。
3. 取出研究后的芯片，装入武器平台的芯片槽。

研究结果保存在**这一个芯片**上，不是全局解锁。更换芯片时，新芯片必须具备当前已安装武器所需的容量和形态许可，否则平台会拒绝更换。

| 芯片研究 | 平台效果 |
| --- | --- |
| 武器扩容 I / II | 各增加 2 个武器位，基础 2 位逐步扩到 6 位 |
| 浮游炮平台模式 | 再增加 2 位，达到 8 位，并允许安装改造形态浮游炮 |
| 散热 I / II | 各提高基础散热的 20%，两级合计提高 40% |
| 战术 HUD | 解锁战术显示与交互 |
| 其他平台分支 | 护盾、移动、防护、辅助与探矿等能力，以研究站中的前置和费用为准 |

浮游炮的榴弹、医疗、电浆与狙击形态，需要把**浮游炮本体**另行放进研究站改造；只升级芯片不会改变炮的形态。

## 作为合成材料

研究站、数据异步处理工厂、数位化封包样板供应器等设备也使用芯片作为合成材料。此类合成会消耗芯片；装在武器平台内的芯片则作为持续生效的升级载体。建议为合成和研究分别准备芯片，避免消耗已有研究成果的芯片。
