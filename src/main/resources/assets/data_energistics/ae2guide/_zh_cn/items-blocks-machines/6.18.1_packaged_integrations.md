# 封包机器集成

各页按 Mod 列出已注册的封包机器、连接目标、机器准备和输入输出规则。通用接单流程见[数位化封包样板供应器](6.18_digital_packaged_pattern_provider.md)。

| 集成 | 主要机器 |

| [Draconic Evolution](6.18.1.2_draconic_evolution.md) | 聚合合成核心与注入器 |
| [Actually Additions](6.18.1.3_actually_additions.md) | 充能台、原子再构机 |
| [Ars Nouveau](6.18.1.4_ars_nouveau.md) | 附魔装置、灌注室 |
| [Occultism](6.18.1.5_occultism.md) | 灵火、物品合成仪式 |
| [Botania](6.18.1.6_botania.md) | 花药台、魔力池、精灵门、泰拉凝聚板、符文祭坛、植物酿造器 |
| [Extended Crafting](6.18.1.7_extended_crafting.md) | 工作台、组合合成、末影／通量合成器、量子压缩器 |
| [Avaritia](6.18.1.8_avaritia.md) | 压缩工作台、无尽工作台、中子压缩器、无尽锻造 |

| [Embers](6.18.1.13_embers.md) | 炼金台 |
| [Forbidden Arcanus](6.18.1.14_forbidden_arcanus.md) | Hephaestus Forge |
| [Goety](6.18.1.15_goety.md) | Dark Altar |
| [Astral Sorcery](6.18.1.16_astral_sorcery.md) | 星辉祭坛、灌注器 |

支持范围以列出的机器为准，不会自动扩展到同一 Mod 的所有方块或配方。每次接单仍会按当前配方和机器状态执行原生检查。
