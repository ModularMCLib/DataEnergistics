# Astral Sorcery（星辉魔法）

接口会动态注册 Astral Sorcery 的流明类型、星座和液态星辉资源。

| 资源 | 连接与用途 |
| --- | --- |
| 流明 Lumen | 接口建立原生流明源节点；ME 网络中可用的流明由 Astral Sorcery 网络读取，附近的外部流明源也可导入 ME。 |
| 星座 Constellation | 用 Astral Sorcery 自带的链接工具，把接口传输节点连接到正在请求星座的接收器；符合配方要求的星座由 ME 网络发送。 |
| 液态星辉 Liquid Starlight | 从连接到接口外部流体输入端的容器或管道导入 ME 网络。 |

Astral 的原生传输包也可把已连接接收器产生的星座记录为 AE 资源。
