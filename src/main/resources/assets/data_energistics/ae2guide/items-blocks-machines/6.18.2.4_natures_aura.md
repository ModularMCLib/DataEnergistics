# Natures Aura

The interface uses one Natures Aura AE resource to link chunks that contain aura. Bind a block position in the chunk with the connector. You do not need to link an altar block itself.

- INPUT or BOTH links allow aura to flow from the ME network into the chunk.
- PULL or BOTH links allow aura above the reclaim threshold to return to the network.
- Aura is replenished at low levels and reclaimed at high levels. A hysteresis band between thresholds prevents rapid direction changes.

The chunk must have valid Natures Aura data. The interface transfers existing aura and does not replace native machine structures or environmental requirements.
