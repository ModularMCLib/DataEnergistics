# Advanced Digital Annihilation Core

<ItemImage id="data_energistics:advanced_digital_annihilation_core" scale="6" />

The Advanced Digital Annihilation Core is made in the [Data Reassembler](6.3_data_reassembler.md), combining formation and annihilation cores into an advanced material.

<Recipe id="data_energistics:data_reassembler/advanced_digital_annihilation_core" />

## Ingredients per operation

| Ingredient | Amount |
| --- | --- |
| ME Controller | 1 |
| Formation Core | 16 |
| Annihilation Core | 16 |
| ME P2P Tunnel | 4 |
| Quantum Entangled Singularity | 6 |
| Data Residual Crystal | 3 |
| Data Processor | 8 |
| Digisidian Memorize Ingot (tag) | 7 |
| Data Corrosion Liquid | 2250 mB |
| Data Flow | 1567 |

The base output is **one core**. Supply **16 of each** core type, and put the liquid and Data Flow in their separate fluid and special resource inputs.
