# 数位化封包样板供应器

数位化封包样板供应器把 AE2 的样板订单交给真实的第三方机器执行。它会检查配方、结构、机器占用、库存和能源，接收整份任务后把材料投入目标机器，最后回收真实产物和返还物。

## 封包发配流程

1. CPU 准备材料；
2. 供应器检查样板、机器、连接、结构、库存和能源条件；
3. 检查通过后，供应器接收整份材料并占用目标机器；
4. 适配器把材料投入真实机器；
5. 原生机器完成加工；
6. 适配器回收产物、容器和约定的返还物；
7. 供应器把回收物放入返回栏；
8. 产物回到 ME 网络或交给等待中的 CPU。

机器预检查失败时，供应器会直接拒绝接单，材料仍留在 CPU。CPU 有材料但供应器没有材料，通常说明机器结构、链接、配方或库存检查没有通过。

## 摆放与连接

独立封包供应器只发现相邻机器：供应器的启用面要朝向目标机器，供应器与目标必须直接相邻，中间不能隔线缆、箱子或空气。目标机器的外围结构、基座、注入器、光路和能源线路仍按原 Mod 的规则单独搭建。

自适应供应器可以在供应器槽中放入封包供应器，再用[均分连接器](6.19_data_distribution_connector.md)潜行右键自适应供应器方块并右键目标机器。远程链接只能替代物理相邻位置，不能替代目标机器的多方块结构；供应器和目标机器都必须位于同一维度并保持区块已加载。

## 样板编码要求

1. 样板必须包含正确的配方类别和具体配方 ID，建议从 JEI 或 EMI 转移配方后编码；
2. 只手动填写输入输出而没有配方信息的普通加工样板，不能进入封包发配；
3. 修改输入输出不会自动把原配方 ID 换成另一条配方；
4. 新匹配规则启用后，旧样板需要重新编码；
5. 样板数量通常填写单轮配方数量，批量执行由目标机器的容量决定；
6. 桶、容器、催化剂、工具和保留材料要按该机器小节的规则声明；
7. 接单后不要让玩家、管道或其他机器同时移动任务材料、返还物和产物。

输出槽可以选择完全匹配、ID 匹配或 Tag 匹配，但数量仍必须准确。ID 匹配只忽略组件差异，Tag 匹配必须由配方明确声明；它们不会绕过原生机器的输入和结构检查。

## 通用接单条件

- 供应器在线，且没有被合成锁阻止；
- 目标机器和检查范围内的区块已经加载；
- 目标机器没有被另一份封包任务占用；
- 输入、输出和机器外围库存通常为空；
- 目标机器能够选择样板记录的那条配方；
- 能源、魔力、魔源、灵气、光照、灵魂、经验和结构加成由原生机器自行提供；
- 目标机器的输入槽、输出槽、注入器、基座等共享部件也会参与占用检查。

接单成功后，任务材料属于当前封包操作。不要从机器中手动取出材料，也不要通过另一条管道抢先抽走产物。

## 动态批量与容量

容量会随能源、输入槽、输出槽、堆叠上限、结构状态和原生机器进度变化，不是固定的 64 个。单台机器同一时间仍只由一份封包操作持有；一份操作可以包含多轮逻辑合成。

当前声明了批量路线的主要机器包括：

- Mekanism More Machines 六种 Large 大机器：按端口接收量和输出容量持续补料；
- Ars Nouveau 精灵门：受材料、产物堆叠和供魔量限制；
- Botania 魔力池：按堆叠上限逐件调用原生转换；
- Occultism 灵火：按输入、输出堆叠限制投栈；
- Actually Additions 原子再构机：按能量、堆叠和透镜实际耗能计算数量；
- 其他适配器会在自身规则允许时声明容量。

花药台、符文祭坛、泰拉凝聚板和没有安全批量入口的路线保持单轮操作。Avaritia 与 Extended Crafting 不会循环取出输出槽来伪造批量；复杂返还物配方也按单轮容量处理。

### Mekanism More Machines

Large 机器需要完整外壳、输入输出端口和供能。供应器会按端口接收量和输出容量把材料分批投入，并由原生并行度、能源和时间决定速度。输入端、输出端或结构被其他任务占用时会拒绝接单。

### Malum

连接对应的灵魂加工机器，保证灵魂容器、输入和输出为空，并按原生配方提供灵魂和能源。精魂聚焦等预装主材料可以作为保留输入；普通耗材不要预先塞入。额外奖励会按实际回收结果记录，不要把它们当作确定产量写进基础输出。

### Natures Aura（自然灵气）

连接自然灵气机器本体，预先准备有效的自然灵气环境、催化方块和结构。机器输入输出要清空，灵气由原生系统消耗；封包只负责投料、启动和回收，不提供灵气。

### Neo Vitae

连接对应的 Neo Vitae 机器本体，按配方准备外围部件和能源。检查范围内的机器、容器和结构必须保持空闲；封包按原生输入顺序投料，产物和返还物以实际回收结果为准。

### Embers

连接 Ember 机器本体，先搭好原生结构并提供 Ember。输入槽、输出槽和管道不要被其他任务占用；封包调用原生加工，不能用空箱子或假定燃料代替真实 Ember。

### Forbidden Arcanus

连接目标机器并准备原生结构、灵魂、能源和配方需要的外围材料。封包不会绕过原生仪式、结构或容器要求，输入和输出槽应在接单前清空。

### Goety

连接 Dark Altar，预先准备激活物、基座、灵魂笼和原生仪式结构。封包使用独立任务玩家执行可支持的物品制作、附魔和定位仪式，经验费用按封包路径为零，但灵魂消耗、结构和材料仍由原生仪式负责。召唤或实体转化类仪式不属于此路线。

## 可复用输入

普通耗材会按发配数量增加；可复用输入按同时运行的物理机器数量准备，不会按每轮普通产物返还。机器适配器只有在能够报告实际返还物品 key 和数量时，才会加入可复用输入会话。

Ars 灌注室是典型例子：制作 64 个精华时，CPU 准备 64 个中央耗材，以及每台并发机器各一套基座催化剂。每轮由原生机器加工，实际回收的催化剂留在该会话中；整批结束或取消到安全点后，再定向归还所属 CPU。

可复用输入不能同时写成普通输出。会话中的材料、机器进度、session ID 和 operation ID 会一起保存；机器未完成时不能提前退款或重复投入。

## 恢复与拆除

成功接单后，封包会固定目标机器和需要占用的外围部件。删除连接器或更换方块不会让同一份材料自动重新分派。

- 区块卸载不等于拆除，任务会等待区块重新加载；
- 机器或占用部件真正被替换时，旧操作会进入拆除恢复流程；
- 拆除供应器时，有任务或返回库存可能生成封包任务恢复凭证；
- 使用凭证前，需要把相同宿主放回原维度、原位置，并保证回收库存有空间；
- 凭证只能兑换一次，不能跨宿主类型或错误位置使用；
- 不能用配方预期值补造已经丢失的材料，恢复只承认实际保存的资产；
- 回收槽暂时装不下的内容会继续保存在任务状态中，之后重试。

## 阶段化排障

| 现象 | 优先检查 |
| --- | --- |
| CPU 有材料但供应器没有接单 | 配方类型/ID、供应器在线状态、合成锁、连接目标、机器结构、库存和接单数量 |
| 供应器接单但机器没有材料 | 目标面、输入模式、机器是否被占用、输入槽容量和区块加载 |
| 机器有材料但不开始 | FE、魔力、魔源、灵气、光照、原生结构、配方选择和运行开关 |
| 机器完成但产物留在机器里 | 输出槽容量、产物组件、返还物和供应器在线状态 |
| 产物进了返回槽但 CPU 不完成 | ME 网络容量、等待中的完整 AEKey、输出匹配模式和任务提交时间 |
| 第一轮完成，第二轮卡住 | 残留物、输出槽、批量容量、结构变化、能源和运行期异常 |
| 拆除后无法恢复 | 宿主类型、维度、原位置、恢复凭证是否已经使用以及返回库存空间 |

未列出的机器或配方不会因为属于同一个 Mod 就自动获得支持。适配清单表示当前存在对应适配路线；具体配方仍应以目标 Mod 版本、原生结构和实际游戏验证为准。
