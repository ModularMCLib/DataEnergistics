# Universal Terminal

The Universal Terminal combines supported terminal functions in one cable part. Switch between installed terminal interfaces at the same position.

<ItemImage id="data_energistics:universal_terminal" scale="6" />

## Combining terminals

This is a dynamic shapeless recipe. Put **two different supported terminals** in the crafting grid to create a Universal Terminal containing both functions.

| Input | Result |
| --- | --- |
| ME Terminal + ME Crafting Terminal | A Universal Terminal containing both functions |
| Universal Terminal + a supported terminal not yet installed | Adds that function to the existing Universal Terminal |

Built-in support covers the ME Terminal, ME Crafting Terminal, ME Pattern Access Terminal, and ME Pattern Encoding Terminal. Other types require a compatibility adapter. JEI and EMI also show the combining rules.

Each operation requires exactly two occupied input slots. Duplicate terminal types cannot be installed, and two Universal Terminals cannot be merged directly. The added terminal is consumed as an ingredient.

## Installation and switching

1. Place the Universal Terminal on a cable connected to an operational ME network.
2. Open it and use the terminal switch button: left-click for the next type or right-click for the previous type.
3. You can also select a type from the list of installed terminals.

The item tooltip lists installed types. Only installed functions are available, and crafting or pattern access still requires the corresponding network facilities.

The portable overlay is the [Player Terminal](7.7_player_terminal.md), unlocked through player research. It has a separate entry point from this cable part.
