# Goety

接口按每个坐标轴七格的范围自动发现已加载的黑暗祭坛。把诅咒牢笼放在祭坛正下方，并确保牢笼也在扫描范围内。

| 资源或自动行为 | 目标 |
| --- | --- |
| Goety 灵魂 | 正在运行仪式的黑暗祭坛下方的牢笼。接口按当前仪式的费用给笼中的图腾或符合条件的所有者补充灵魂。 |
| 附魔经验 | 支持的 Dark Altar 附魔仪式；适配器自动从 ME 网络为仪式施法者补充经验。 |

施法者启动受支持的附魔仪式时，接口自动补充经验。由封包供应器发配的附魔仪式见 [Goety 封包集成](6.18.1.15_goety.md)。
