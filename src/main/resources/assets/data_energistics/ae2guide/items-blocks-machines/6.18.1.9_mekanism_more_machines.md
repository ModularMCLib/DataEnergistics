# Mekanism More Machines

This integration registers only when Mekanism More Machines and Applied Mekanistics are installed. It covers the six Large machines below, not standard machines, factories, or the Replicator. Linking a bounding block resolves its main machine. The operation claims both positions.

| Large machine | Input → output | Conditions |
| --- | --- | --- |
| Chemical Infuser | Two chemicals → chemical | Input/output slots and tanks are empty. |
| Pigment Mixer | Two pigments → pigment | Input/output slots and tanks are empty. |
| Solar Neutron Activator | Chemical → chemical | Native sunlight and operating conditions remain required. |
| Electrolytic Separator | Fluid → two chemicals | Both dump modes are IDLE, and both outputs are declared. |
| Rotary Condensentrator | Fluid ↔ chemical | Select a direction before submission and keep the mode unchanged. |
| Antiprotonic Nucleosynthesizer | Item + chemical → item | Full-round chemical, energy, and input/output capacity are available. |

The provider refills actual input ports and collects each output according to its capacity. Machine slots, tanks, processing mode, and structure must be idle and valid.
