# Extreme Capacity Interface

The Extreme Capacity Interface is a high-capacity version of the ordinary ME Interface. It can reserve items, fluids, and other AE Keys from the ME network, expose them to adjacent or remote devices, and return inserted contents through its Return Slots.

- The part form mounts on a cable and interacts only from the side it faces.

Hold the upgrade and right-click an ordinary ME Interface block or part to upgrade it in place while preserving its configuration and internal data. Each conversion consumes one upgrade item.

## Pages and slots

Each page provides **9 configuration/reserve slots** and **18 Return Slots**. The interface starts with two pages; each Capacity Card adds two more, up to three cards:

| Capacity cards | Available pages | Configuration/reserve slots | Return Slots |
| ---: | ---: | ---: | ---: |
| 0 | 2 | 18 | 36 |
| 1 | 4 | 36 | 72 |
| 2 | 6 | 54 | 108 |
| 3 | 8 | 72 | 144 |

Reserve and return slots use long-width amounts instead of Minecraft stack capacity. Capacity Cards add pages and slots; they do not change the amount limit of one slot.

Removing a Capacity Card locks its pages. Locked pages stop stocking and accepting new contents, but preserve existing inventory and configuration. Reinstalling enough cards restores them.

## Configuration, reserve, and return

- A configuration slot stores the AE Key and finite reserve amount.
- A reserve slot provides real inventory to adjacent or remote targets.
- A Return Slot accepts items, fluids, or other resources and continues trying to send them back to the ME network.
- Clearing a configuration does not silently delete real stock.
- Remainders rejected by the network stay in the interface and are retried later.

Click the gear beside a configuration slot to edit a finite amount, an infinite network mapping, and its connector policy independently. Toggling the mapping does not rewrite the amount field.

With an infinite mapping enabled, the configuration displays `∞` and the reserve slot shows the AE Key's live network availability. The network is debited only on actual use: SIMULATE does not change inventory, while MODULATE debits only the successfully extracted amount.

Clearing the configuration removes the mapping. Real stock from that slot is returned according to the amount the network actually accepts; rejected remainders remain stored.

## Remote links

Remote links require the full block form; interface parts cannot be connector hosts. Hold a [Distribution Connector](6.19_data_distribution_connector.md), sneak-right-click the interface block, use `Ctrl + Shift + Wheel` to select a slot, and right-click the actual target face to add or remove a link for that slot.

Each slot independently stores:

- link order;
- `INPUT`, `PULL`, or `BOTH` mode;
- priority or round-robin policy;
- link traversal cursor;
- source cursor for remote targets.

One slot's policy and progress never alter another slot. Use the connector page for binding, copy, cut, paste, and unlink controls.

## Amount expressions

Amount entry uses the same long-width expression parser as crafting requests. It supports parentheses, arithmetic, powers, scientific notation, and suffixes:

```text
2*(3g+4k)
1e6
2^63-1
```

The converted amount must be an integer no greater than `Long.MAX_VALUE`. Saving `0` clears the configuration marker. Fluids and other resources are converted to base units before the integer and upper-bound checks.

## Card removal and recovery

Removing a Capacity Card does not clear locked pages. Locked pages stop stocking and new insertion, but keep inventory, AE Key mappings, remote links, and configuration. Reinstall enough cards to restore access.

Before dismantling the interface, make sure the Return Slots can accept contents waiting to return to the network. Remainders that cannot be accepted immediately stay in the interface rather than being discarded.

## Troubleshooting

- A page is unavailable: check Capacity Card count and whether the selected page is locked.
- A remote target receives nothing: confirm a full-block host, an unlocked slot, and `INPUT` or `BOTH` mode.
- Pulled contents do not appear: check the target output face, `PULL` or `BOTH` mode, and Return Slot space.
- Infinite amount appears unchanged: the display is live network availability; the actual debit happens when contents are successfully extracted.
- Items remain after clearing a mapping: the network rejected some remainder and it will be retried.
- An expression is rejected: ensure it evaluates to an integer no greater than `Long.MAX_VALUE`.
