# 通用终端

通用终端把多种已支持的终端功能合并在一个线缆贴片中。放置后，可在同一位置切换已装入的终端界面。

<ItemImage id="data_energistics:universal_terminal" scale="6" />

## 合并制作

这是动态无序合成，不需要固定摆放形状。合成网格中只放**两种不同的受支持终端**，即可得到包含这两种功能的通用终端。

| 输入 | 结果 |
| --- | --- |
| ME 终端 + ME 合成终端 | 包含这两种功能的通用终端 |
| 通用终端 + 尚未装入的受支持终端 | 在原通用终端中追加该功能 |

内置支持 ME 终端、ME 合成终端、ME 样板访问终端和 ME 样板编码终端；其他类型需要对应的兼容适配。可用合成规则也可在 JEI / EMI 中查看。

一次合成必须恰好占用两个非空槽。相同类型不能重复安装，两个通用终端也不能直接合并。新增功能会消耗作为材料投入的终端。

## 安装与切换

1. 把通用终端贴在线缆上，让它接入可用的 ME 网络。
2. 打开终端，使用终端切换按钮：左键切换到下一种，右键切换到上一种。
3. 也可以通过已安装类型列表选择要使用的终端。

物品提示会列出已经安装的终端类型。只有实际装入的类型才能使用；合成、样板访问等功能仍需网络中的 CPU、样板供应器等相应设施。

随身的小界面属于[玩家终端](7.7_player_terminal.md)，需要玩家强化研究；它与这个线缆贴片是两套入口。
