## 改造站升级

将工具放入改造站，为物品分别研究储能、加速、伤害、挖掘速度、数据流存储和工具特技。升级卡作为研究材料消耗，元件工作台不再安装卡片；旧卡不会解锁研究。

储能研究共三级，最大容量为基础容量 × (1 + 8 × 储能等级)；加速研究共三级。切割刀保留基础256字节数据流存储，研究后增加到512字节。其他工具的数据流存储由独立研究解锁。

| 工具 | 特技研究 |
| :--- | :--- |
| 水晶剑 | 满冷却攻击消耗20数据流叠加进制冗余 |
| 水晶斧 | 消耗20数据流连锁伐木 |
| 水晶镐 | 消耗20数据流复制矿物 |
| 水晶锄 | 消耗20数据流保持耕地湿润 |
| 水晶锹 | 消耗20数据流范围挖掘，潜行右键切换范围 |
| 切割刀 | 传送锚选择范围由9区块扩大到11区块 |

进制冗余只负责叠层附加伤害与满层爆发；水晶剑、光剑和磁轨炮数据流弹均只叠加冗余。进制凝滞是独立效果，只暂停生物AI，结束后恢复原有AI状态，不限制玩家操作。
