# 数位化封包样板供应器

数位化封包样板供应器把 AE2 的加工订单交给真实的第三方机器执行。供应器检查配方身份、连接、机器结构、库存和能源条件，通过后才接收整份材料；原生机器完成加工后，供应器回收产物和实际返还物。

- 要从 ME 网络供给灵气、灵魂或血液等资源，见[数位化供应接口](6.18.2_digital_supply_integrations.md)。

## 连接机器

独立封包供应器只发现相邻目标。供应器的启用面要朝向机器，二者之间不能隔线缆、箱子或空气。机器周围的基座、注入器、光路、魔力和能源设施仍按原 Mod 要求搭建。

自适应供应器可在槽中装入封包供应器，再用[均分连接器](6.19_data_distribution_connector.md)潜行右键自适应供应器方块并右键目标机器。远程链接仍要求供应器和目标在同一维度且相关区块已加载。

## 样板与接单

- 样板需要正确的配方类别和具体配方 ID，推荐从 JEI 或 EMI 转移配方后编码。
- 编辑输入或输出会保留原有配方 ID。更换配方时重新转移，使用旧匹配格式的样板时重新编码。
- 单轮输入数量按配方填写。只有声明了安全批量入口的机器才会合并多轮。
- 桶、容器、催化剂、工具和保留材料遵循对应集成页的输入与返还约定。
- 输出匹配模式可以使用完全匹配、ID 或配方声明的 Tag，数量仍须准确。

接单前，目标机器和被占用的外围部件通常需要为空且空闲。机器必须能选中样板记录的配方，原生结构和能源条件也要满足。预检查拒绝时，材料仍留在 CPU。成功接单后，材料、机器和外围组件由当前任务持有，不要让玩家、管道或其他任务同时移动。

## 批量与可复用输入

批量上限随能源、机器槽位、产物空间和原生进度变化。一台机器同一时间只由一份任务持有；一份任务可能包含多轮逻辑加工。具体支持的机器和边界见各集成页。

数据核心／三位一体 CPU 为每台并发运行的机器借用一套可复用催化剂，耗材数量随加工轮数增加。会话在轮次之间持有催化剂，整批结束或达到可安全取消的状态时归还 CPU。由会话管理的催化剂只填在输入槽。

## 恢复与排障

卸载区块会暂停任务。更换机器或已占用的结构部件时，任务会进入恢复流程，取回实际持有的物资。

拆除仍有任务或回收物的供应器时，可能掉落一张一次性恢复凭证。把同种供应器放回原维度的原位置，清空回收库存后使用凭证。回收库存放不下的物品会留在任务中，等有空位后再转入。

| 现象 | 优先检查 |
| --- | --- |
| CPU 有材料但供应器没有接单 | 配方类型与 ID、供应器在线状态、连接目标、结构、库存和数量 |
| 供应器已接单但机器没有材料 | 连接面、输入模式、目标占用、槽位容量和区块加载 |
| 机器有材料但不启动 | 能源、魔力、灵气、原生结构、配方选择和运行开关 |
| 产物留在机器里 | 产物数量与组件、原生返还物、供应器在线状态 |
| 产物进入回收库存但 CPU 仍在等待 | ME 存储空间、CPU 等待的物品 key、样板输出匹配模式 |
| 第一轮完成后卡住 | 槽内剩余材料、输出空间、电力与结构变化 |
