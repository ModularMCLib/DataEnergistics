# Natures Aura

| Machine/route | Target | Admission and dispatch |
| --- | --- | --- |
| Nature Altar | Nature Altar block | Use one recipe round; native altar structure, catalyst blocks, and aura conditions are valid. |
| Crimson Altar | Nature Altar block in the Nether | Uses the target block and the shared native ALTAR structure check. |
| Ritual of the Forest | Soil directly below the sapling | Prepare an empty wooden base; pattern includes materials, matching sapling, and required gold powder. |
| Offering Table | Offering Table | One round contains 1–16 ingredients and one activation item; insert ingredients first, then the real activation entity. |

The Forest Ritual places gold powder and saplings in recipe order before calling native growth. Every route consumes real aura or uses native environmental conditions. The provider does not create aura.
